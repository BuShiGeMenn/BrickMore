一、最新数量与对应关系（以此为准）

两位AI各生成40,000个独立模型，并为每个模型制作5条训练提示词，即各200,000条训练记录。
正确关系是：类别 → 真实结构变体 → 一个独立模型 → 描述这个同一模型的L1、L2、L3、L4、L5五条训练提示词。

三、五级描述同一实际模型
promptType固定：L1=minimal；L2=basic_structure；L3=geometry；L4=proportion；L5=comprehensive。
L1：类别、子型与核心辨识结构，中文约15—35字、英文约6—18词。
L2：增加主要部件、数量与基本空间关系，中文约25—60字、英文约12—30词。
L3：增加形状、轮廓、厚度、方向、连接及至少两项几何属性，中文约40—90字、英文约20—45词。
L4：增加相对比例、尺寸关系、部件位置与间距，中文约60—130字、英文约30—65词；使用实际模型支持的相对比例，不给绝对坐标。
L5：综合类别、子型、轮廓、比例、部件数量、厚度、连接、空腔、颜色分区与多视图特征，中文约100—220字、英文约50—110词。
长度范围用于Caption。五级包含的事实集合逐级增加，每级描述均被同一模型满足；缺少描述不是否定该特征。不能L1称圆杯、L3称方杯，不能L2称四腿、L5称单柱，不能写不存在的部件或把所有等级写成同义扩写。L1/L2允许省略细节，不能与实际几何冲突。
执行流程：先规划同一实例的geometryPlan和五级意图，再用L5完整生成提示词生成一次模型并验证；最后从该实际已验证模型核对/整理五级Caption。如果几何不符合预定核心设计，应修正几何；不能仅把文本改成失败几何来伪装通过。重采样或语义修复改变实际比例/细节后，更新该模型5条描述并重新检查一致性。
每模型有generationPromptZh/En（实际使用的L5完整建模指令）；每条训练记录有captionZh/En、voxelPromptZh/En。各级voxelPrompt为该级Caption加固定技术与必要类别语义规则，每条独立可读，不写“同上”。L1—L4不再次生成几何，使用同一已验证模型作为训练目标；它们的存在不意味着低细节文本能唯一确定所有未描述的几何。
Caption只描述物体，不含模型ID、seed、路径、hash和验证指令。中英文事实对齐。不同模型的短L1文字可能一致，这不等于目标几何重复；记录关联由modelId/recordId维护，不能靠给文本加编号制造独特性。训练默认使用captionZh/En作为输入；voxelPrompt是带执行规则的备用输入，标明实际采用哪种字段。

四、坐标、颜色与体素硬约束
坐标为唯一非负整数，0<=x,y,z<48；X左右、Y向上、Z前后；最低真实接地点Y=0。设局部forward用于车头、镜头、琴面等功能方向，记录与全局坐标的关系。颜色为0—255整数RGB三元组，使用少量连续语义分区，不用透明体素或随机逐点颜色。
每模型必须750—1250个占用体素，优选约1000。形成一个六邻域连通分量，附件与所属主体共享面，角点/斜对角接触不算连接。保留物体真实悬挑，附件根部有清晰截面和足够厚度；有意义的窄连接优先至少2体素厚，重采样后再次检查。禁止用无关撑杆连接离散部件。真实孔洞、内部空腔、封底、层板空隙与轮组分离应实际存在。
禁止额外底板、展示台、背景墙、地面、文字、标签、无关支撑、漂浮装饰、单体素细丝。类别自身的脚、底环、船底、塔底或真正承重框架可以存在，但必须在设计中明确，不能伪装成物体部件补数。

五、从原始几何重采样
先完整构造原始参数几何，记录initialVoxelCount。超过1250时降低分辨率，低于750时提高分辨率；XYZ采用相同线性比例，初始建议s=(1000/initialVoxelCount)^(1/3)。在当前约定中s<1表示减少空间采样密度，s>1表示增加。每次均直接从原始几何重建网格，禁止对已重采样点云累积缩放。由于空腔和薄壁，公式只作为初始估计，可搜索合理比例以命中范围。
记录每次尝试的比例、实际数量和失败原因。每次检查连通、必需部件、孔洞、封底、连接截面、表面特征和48边界。若无法同时满足，修改有意义的原始几何参数并同步更新设计描述，再重新生成；设每条最多20次自动尝试，失败写入retry_queue并重新规划，不永久丢弃配额。
禁止随机删体素、复制体素、填实空腔、无意义内部填充或追加随机浮雕来命中数量或绕过去重。不得为hash不同添加签名凸点、指纹条纹、随机小块。规范化重复坐标只作为栅格清理，并记录数量。

六、语义与可见特征的实际验证
逐部件验证数量、所属位置和连接；part标签存在不等于结构正确。容器需要洪泛或等价几何验证：空腔与指定开口相通，底部封闭，无意外侧漏；mug把手孔应真实贯通且上下根部接杯壁；birdhouse入口通向居室；bottle口连接颈腔与瓶腔。检查轮子位置/数量、椅腿支撑、琴颈连续截面、层板间隙等专属特征。
按钮、镜头端面、车窗、琴键等定位于类别合理功能锚点，并占据/替换外壳体素，至少一面暴露空气，与所属部件六邻域连接。记录featureId、ownerPart、coordinate、localPosition、airNeighborCount、exposedFaceDirections、connectedToOwner、expectedViews、rayClear、unoccludedPixels。先检查功能位置，再检查暴露与预期视角无遮挡；不能把特征挪到轮廓极点来方便通过。比例或形态变化后重新定位。不存在该类特征的检查标not_applicable并说明，不虚构动物眼睛。
输出正视、侧视、俯视及斜视预览；用实际网格投影/渲染证据检查关键特征。预览可拼成preview.png。光照、阴影和背景不能改变实际占用或遮蔽验收；记录镜头方向与视图约定。

七、按独立模型去重与两任务协作
历史索引historical_models_55255.jsonl含旧18,000、25,065和最近12,190共55,255个模型的原有占用hash；包内未附旧模型完整坐标。
exactOccupancyHash算法：按(x,y,z)元组升序排列，串联'x,y,z'，各项间用';'分隔，无尾分隔，UTF-8 SHA-256，忽略颜色。本任务40,000独立模型逐个与历史和任务内模型集合比较；重复时重新设计对应实例，不能添加签名凸点/噪声/随机浮雕改hash。
对新模型另算canonicalGeometryHash：枚举48种轴置换与正负组合，每种变换各轴减最小坐标后，按坐标排序串联并算SHA-256，取48个hash中字典序最小值，忽略颜色。记录算法版本。用于识别新批平移、旋转、镜像同形。对近重复结合归一化轮廓、部件关系与主尺寸比例审核，仅微小无意义差异的模型重新设计。
dedup_index.jsonl每个模型一行，因此本任务40,000行、两任务80,000行；包含modelId、category、exactOccupancyHash、canonicalGeometryHash、designSignature、geometryPlan、variantId、semanticGroupKey。五条训练记录引用相同几何是规定关系，不得作为五份重复模型丢弃。
能够访问另一任务索引时实时对比；尚未交换时crossShardDedupStatus=awaiting_merge。历史旧坐标缺失时historicalCanonicalDedupStatus=unavailable_coordinates，只能证明历史原始hash比较情况，禁止报告历史旋转/镜像/近重复已排除。
最终合并实际模型索引，对80,000模型执行A/B去重。撞项优先保留A，要求B重新设计该类别模型，并同步更新该模型5条训练记录；修复后再次检查类别/模型配额与五级配对。名称、命名空间、seed不同不代表结构已去重。
如划分训练/验证/测试，同modelId的5条描述必须同split；geometryFamilyId及同源几何族尽量整体划分，防止近似模型泄漏。A/B是生产分工，不直接作为train/test划分。

八、每模型只输出一份几何、多格式由同一JSON派生
模型路径models/<category>/<modelId>/，包含model.json、model.npz、model.obj、model.mtl、model.vox、preview.png、validation.json、prompts.json（该模型恰好5条配对记录）。每模型的6种主要输出各一份，不能每描述再复制一套作为新增模型。
先验证规范JSON，再从该JSON派生所有模型格式。model.json至少包含datasetVersion、shardId、modelId、object/category、categoryId、variantId、geometryFamilyId、semanticGroupKey、tier=detailed、modelSeed、coordinateSystem、gridSize=[48,48,48]、requestedVoxelRange=[750,1250]、preferredVoxelTarget=1000、initialVoxelCount、actualVoxelCount、generationPromptZh/En、semanticFeatures、geometryPlan、resamplingHistory、voxels、validation、promptRecordIds（完整5个recordId）。不要为同一个模型指定互相矛盾的promptLevel值；等级属于训练记录。
每voxel有x,y,z,color:[R,G,B],part，长度等于actualVoxelCount。NPZ至少coords(N,3)、colors(N,3)、occupancy(48,48,48)，occupancy[x,y,z]与JSON逐点一致。VOX标准内部Z向上，写出时JSON(x,y,z)->VOX(x,z,y)，记录轴变换，读回逆变换并核对坐标/颜色。OBJ正确引用MTL，删除共享内部面只影响表面网格。生成器、验证器、渲染器坐标一致。
validation.json记录实测数量、六邻域组件数、坐标界限、真实落地点、逐部件/开口/空腔/连接/特征结果、重采样尝试、格式读回、hash、失败原因和pending/not_applicable。不得预填true。

九、200,000条训练记录与模型的精确关联
all_prompts.jsonl/CSV本任务恰好200,000条，各级40,000；联合两任务all_400000_prompts.jsonl/CSV恰好400,000条，各级80,000。
一条JSONL训练记录至少包含datasetVersion、shardId、recordId、modelId、category、categoryId、variantId、structuralVariant、geometryFamilyId、semanticGroupKey、promptLevel、promptType、modelSeed、tier、captionZh、captionEn、voxelPromptZh、voxelPromptEn、requiredParts、invariantFeatures、changedAttributes、designSpec、requestedVoxelRange=[750,1250]、gridSize=[48,48,48]、modelJsonPath、modelNpzPath、targetOccupancyHash、targetCanonicalGeometryHash、sharesGeometryAcrossLevels=true、expectedIndependentGeometryAcrossLevels=false。
对每个modelId，必须恰好五条recordId唯一的记录，promptLevel集合={1,2,3,4,5}；五条的模型路径、两个目标几何hash、模型seed、variant和family均相同，文字细节随等级变化。每个模型均有五条记录，每条记录均能找到真实模型。五级完整性/文本中英文对齐/事实与模型一致必须实测验证。
geometryPlan保留实际结构参数和类别变化依据；训练记录可以引用geometryPlan与模型meta，训练文本不塞入ID/hash来避免重复。逐级描述文件与单模型prompts.json、汇总JSONL/CSV应一致；生成器保存实际执行的L5建模提示词，便于复现。
输出按类别和L1—L5拆分的训练子集；模型只存一份，各训练子集引用公共路径。报告modelCount与promptRecordCount两个独立统计，禁止把200,000条提示词算成200,000个模型。

十、执行、验证与交付
实际执行顺序：保存design_manifest → 规划模型及五级意图 → 用L5指令生成每模型一次 → 原始几何重采样 → 实际语义与数据验证 → 核对五级文字 → 导出派生文件 → 独立读回 → 打包。任何模型替换均同步替换其五条记录，保持recordId稳定以便追踪。
先为21类各试运行一个模型（21模型、105条配对描述）；检验全部流程后扩展，合格试运行计入本任务配额。每250模型保存检查点，每1000模型独立读回并报告“已完成模型数/40,000、已完成训练记录数/200,000、失败/待补数”。中断后按状态恢复。
交付manifest.json、all_prompts.jsonl/CSV、dedup_index.jsonl、design_manifest.json、generation_status.json、retry_queue.jsonl、independent_verification.json、README、实际生成程序、独立验证程序、SHA256SUMS。manifest每模型一条，训练文件每模型5条，文件互相映射。
独立验证读取真实JSON/NPZ/VOX/OBJ/MTL/PNG/提示词，检查坐标颜色、体素范围、组件、语义证据、几何去重、21类配额、40,000模型与200,000记录的一对五关系；不能只看生成器true标志。达不到配额的失败模型重做，记录失败原因，不用其他类别替代。
每1000模型做一个分包，共40模型分包；每包包含1000完整模型及对应5000条训练记录、子manifest、验证摘要、README。全量提示词/元数据/索引做metadata包。模型分包与训练记录路径在合并后仍可追溯。检查可用空间、包内完整性及SHA-256；空间允许时可另做整包。
完成报告真实40,000模型、200,000记录、21类数量、各级40,000记录、失败/待补数、历史exact与A/B检查状态。体素结构/数据通过与后续LEGO排砖/物理处理通过分开记录。
按本任务身份和精确表分配执行。若环境只能对话、不能写文件或运行程序，应明确报告能力限制，不虚报模型生成成功。最终模型数量不能靠重复存五份几何达到；80,000模型/400,000提示词是一对五关系。
