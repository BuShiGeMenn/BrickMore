# BrickMore-48 · 630 模型评测集(提示词 + 模型 + 人工判决)

本目录包含用 **BrickGPT-Qwen3-1.7B-BrickMore-48**(48³ 网格,20 砖型)生成的 **630 个乐高模型**,连同全部提示词、验证报告与五人人工判决结果。

## 内容

| 目录 | 说明 |
|---|---|
| `prompts/items_index.json` | 630 条全量索引:id / 类别 / 等级 / 变体 / 批次 / 英文提示词 / 中文翻译 / 模型目录映射 |
| `prompts/levels2_*.json` | 525 条新批提示词原始生成文件(21 类 × 5 级 × 5 变体,与训练集零重叠) |
| `models/<类>/<LxVy>/` | 每个模型 4~5 个文件(见下) |
| `results/best_all.*` | 五人人工判决汇总(105 组 × 6 候选,每组选最佳或判全不合格) |
| `results/raw_failure_autopsy.json` | 525 条 raw 失败病因解剖(重叠/stud 咬合断裂量化) |
| `manifests/` | 生成账本(worker 分工、种子、求解档位、重铺砖数) |

每个模型目录:

- `prompt.txt` — 英文提示词 + 中文翻译
- `raw.txt` — 模型原始输出(逐行 `WxH (x,y,z)`,原始 YX 尺寸约定)
- `raw.ldr` — 原始输出的 LDraw 格式(可直接导入 Blender/LDView 查看)
- `stitched.ldr` — 重铺布局的 LDraw 格式
- `raw_report.json` — 生成统计与验证(砖数/体素/连通分量/错误/时长/token,已去除砖列表冗余)
- `stitched.txt` — 数学兜底重铺后的**保证可拼**布局(无此文件 = raw 本身单连通可拼)
- `fix_note.json` — 仅首批 10 条:重叠 union 修复记录

## 生成协议

采样 t=0.7,种子阶梯 42→104→2026 → 几何验证(run.py validate)→ 重叠 union 修复 → MILP 保形重铺(12s→60s→180s 升级,scipy HiGHS)→ stud 单连通审计。

## 关键统计

- **525/525 全部可拼**(46 条 raw 原生可拼保留,479 条重铺;union 救回 45;28 条难例换种子重生成全部救回)
- raw 一次通过率 **8.8%**(46/525);主要病因:90% 为"贴身不咬合"(砖块并排贴合但上下从不交错咬合,体素层完全连通、stud 层中位裂成 5 块)
- 人工判决:79/105 组有最佳(75%),26 组全部不合格;piano 五级全灭、camera/car 等高细节类最差
- 体积(体素数)逐级增长显著(如 basket L1 2309 → L5 约 1000+;详见 manifests)

## 说明

GLB/OBJ 三维文件与渲染图体积过大(数 GB),未纳入本仓库;`models/` 中的文本形态(WxH 坐标列表)为完整无损数据,可用任何 LDraw/体素工具重建。
