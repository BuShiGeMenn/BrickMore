# 算法标注与验收边界

| 标识 | 作用 | 证据边界 |
|---|---|---|
| `B_exact_grid_assembly_v2` | 已封存 AI_B 的 RGB/Y-up适配、必要条件、受检贪心、有限beam搜索、批处理及导出 | 保持离散占用/RGB；搜索不完备 |
| `exact_grid_assembly_v3` | 增加原 AI_A modelJsonPath 与 AI_B modelPath 索引兼容及路径检查 | 与 v2 相同砖库、支撑及几何政策，不修改输入 |
| `exact_interlocking_v2` | 标准矩形砖候选、支撑锚点前瞻、跨缝与组件债评分 | 错缝和悬挑是启发式，不是力学证明 |
| `B_layer_mrv_exact_cover_v1` | 对首轮搜索失败项进行最少候选格点优先的逐层位集精确覆盖 | 上一层固定第一个解；不保证全局最优或完备 |
| `independent_audit` / `exported_audit` | 从实际JSON/TXT/LDR重新构建格点和独立并查集 | 几何/数据/前缀策略验收，不验证完整物理 |
| `portable_assembly_archive_v1` / `payload_audit` | 打包选中结果、原模型/提示词及相对路径报告，重新打开 ZIP 检查 CRC/SHA 并重建 | 包括明确标注的失败草稿；不把失败回读一致误记为装配成功 |

## 拼接

1. 严格读取唯一整数格点和RGB三元组，显式Y-up→Z-up，不猜轴、不清洗冲突数据。
2. 建立可能stud连接的过近似图：水平边仅同色，竖直stud可异色。此图分离则当前同色矩形单砖高库无法连接；另检每个悬空格点是否至少存在一块具有下方支撑的同色完整矩形砖。保存具体坐标证据。
3. 在最低未覆盖层选择完整同色标准砖，优先覆盖难支撑格点、跨下层真实组件和接缝，使用锚点前瞻防止局部堵塞。有限beam备用搜索同时考虑剩余占用与未合并组件。
4. 对搜索失败项预计算逐层合法矩形，用位集表示覆盖，优先选择可用候选最少的格点并回溯。每次真实提交仍按相同规则验证。
5. 只有通过独立校验的布局可标记成功，全模型必须一个真实stud组件；补充搜索成功才替换初轮失败。没有通过的布局只作草稿，不保证砖数最优。

砖库为extended十一种单砖高矩形砖及其旋转。逐砖要求边界48、无重叠、层高不倒退/跳跃、非地面有直接下方支撑且比例至少10%、最大支撑曼哈顿距离2studs、临时组件不超过64。地面可临时多组件但不参与虚拟合并，侧贴不连接。

## 独立校验

不读取生成器的true标志当作证据。另建占用字典和并查集，从砖尺寸及坐标重建全部格点/RGB，检查库、碰撞、每个放置前缀的支撑和悬挑，只按上下真实stud邻接合并。要求完整覆盖、零新增、零重涂、单组件及接地。

随后从磁盘回读JSON、TXT、LDR。LDR按零件编号、旋转矩阵、20/20/24单位及directRGB逆解，逐砖与JSON比较。源规范坐标原始占用SHA-256按排序的 `x,y,z` 串以分号分隔、无尾分号计算。成功占用逐点相同，因此保留原规范几何hash；不以仅参数摘要代替几何证明。

所有输入/产物记录SHA，并在批次结束后再次独立读回。最终按modelId只选一个通过结果，首轮和补充产物不会重复增加独立模型数量。

## 不保证什么

单砖高、矩形、同色、仅上下stud及下支撑策略限制了可行域。必要条件失败只在这个域内有效；有界搜索失败不是无解证明。没有放松限制、改颜色、填空腔、增底板或补桥提高通过率。

未调用真实静力求解器，未验证重心、抗倾覆、接头力矩、摩擦、stud/tube干涉、插入路径或人工搭建。水平1stud和竖直1标准砖高导致实物比例与等距体素不同。任何“通过”均不得标成物理通过或人工语义质量证明。
