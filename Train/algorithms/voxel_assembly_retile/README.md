# 局部跨接梁与已有砖重铺

新优化通道 `local_monochrome_bridge_retile_v1`。针对键盘/琴体换色接口、桌面与腿根，以及完整分块后未接地的砖组件。沿用原放宽版的同色标准砖库、真实上下 stud 接触、每组件接地、原色与新增＋删除≤2%规则；物理算法和参数不变。

旧连接器主要在空位内追加整块新砖。本通道允许一根同色桥梁同时覆盖原有区域与新增格子：拆除与桥梁相交的旧砖，精确重铺剩余区域，再从实际上下重叠重建连接图。仅接受未接地体素数/组件数严格减少的动作，避免修好一处却反复破坏另一处。优先零新增重铺，再尝试原模型一步邻域内的少量新增。

## 单模型运行

从`Train` 目录运行，Python 3.11+；物理筛查和旧求解回退使用 NumPy/SciPy。

```text
python tools/optimize_assembly_retile.py run your_model.json --out new_result --seconds 8 --physics-seconds 5
python tools/optimize_assembly_retile.py verify new_result
```

输入是原数据集 Y-up 的 `model.json`，也可使用已发布装配包里的 `source.model.json`。`--baseline existing_result` 可从真实 JSON/TXT/LDR 复查旧布局，保留已通过且改动合规的结果。输出目录须新建，已有输出只允许相同源码/配置的复验恢复。

输出包括原模型/可用的原五级提示词副本、独立 `_q6_` 派生目标、实际装配 JSON/TXT/LDR、两个几何检查器一致的验证、物理结果、逐点改动和仅新增失败证据。原模型及原提示词文件不改写；修改后的目标不自动重绑原提示词。几何失败保存 `.draft`，但仍覆盖整个派生目标，不返回掩盖几何的缺失草稿。

默认执行旧自重/完成层筛查。`--physics-seconds 0` 明确只比较几何，输出 `not_attempted_geometry_only` 且物理通过为 false。几何成功不代表实物承载或安装过程通过；始终 `staticVerified=null / fullPhysics=false`。未知咬合力不判为物理通过。

## 固定样例实测

- 此前预览的10个失败模型：新几何通过9个，其中4个不改体素；另5个各新增1–4格。剩余1个仍失败且完整保留。
- 独立失败样例40个：A/B钢琴、桌子各10个，新几何通过38个；其中21个只需重铺，不改体素。
- 12个已发布成功的其他类别样例：12个全部保留，零退步。
- 独立组的每模型搜索预算2秒。新修复40模型共新增80格、删除0格、改色0格，最大改动1.965924%；其中两个失败仍没有伪装成功。
- 10个开发样例使用8秒搜索和5秒物理筛查预算：9个几何通过均仍需未标定咬合力，没有物理通过。

独立组从A/B发布分包02–05的已知失败项中按类别/分片分层抽样，seed 913571；开发组来自分包01。结果是针对失败样例的恢复效果，不是随机总体通过率；尚未重跑80,000全量。详见 [优化报告](reports/OPTIMIZATION_REPORT.md) 和 [逐模型对照](reports/holdout_summary.json)。

## 验证与复现

```text
cd algorithms/voxel_assembly_retile
python -B -m unittest -v test_retile
```

14项新测试覆盖已有砖与新增格共同跨接、真实侧贴拒绝、黑色RGB、48格边界、2%取整预算、保留成功、删除前失败证据、源/提示词字节保留、失败完整覆盖及实际LDR/原色篡改拒绝；原放宽版7项测试也通过。

`benchmark_retile.py` 冻结选样hash、实际源码快照、预算、源/报告SHA；逐项读回实际JSON/TXT/LDR并比对原始文件。输入样例仍使用原发布，清单见报告目录。

```text
python algorithms/voxel_assembly_retile/benchmark_retile.py --cases selected_index.json --samples extracted_samples --out new_benchmark --seconds 2 --physics-seconds 0
```

该实现仍是有界局部搜索。超时或没有找到改进不证明标准砖下无解；零新增重铺、局部桥梁、旧有界回退均保留实际搜索记录。旧源码与旧发布结果保持原版本。
