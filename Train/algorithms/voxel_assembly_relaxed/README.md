# 算法：多接地组件、真实连接砖与接地流装配

明确的放宽几何档，用户允许多个组件但要求每个组件接地且有真实stud连接。目录源码与Q4隔离，不重写旧报告。完整政策、物理边界和下载交付见 [发布说明](../../datasets/relaxed_assembly_80000/README.md)。

- `relaxed_core.py`：独立实际占用、上下stud及接地组件检查和修复调度。
- `real_connectors.py`：同色标准砖分块与预算内的实际局部连接件；每个新增点在原模型一步邻域，保留原色。
- `grounded_flow.py`：完整矩形砖覆盖和真实竖向接触到地面的可达性流，仅为连接证明，非受力。流的地面源聚合不合并几何或物理组件；输出仍由实际砖独立审计。
- `modular_gravity.py`：沿用Q3全部受力、力矩、地面和见证计算，适配本档几何准入；超过原残差门槛的候选只保留为独立复算的拒绝诊断，不算有效见证或物理通过。未知咬合力仍不是物理通过。
- `relaxed_pipeline.py`：保留已复验严格成功、生成独立派生结果、双审计与JSON/TXT/LDR及物理见证回读。

调参样本400模型中真实连接件版本通过330（82.5%），不代表总体率。另做独立选样；全量通过率和60%目标是否达成以发布时 `assembly_summary.json` 为准。原始源字节/提示词不改，新增+删除≤2%，原色不改，删除前真实失败证据和旧核心/地面保护继续保留。
