# Q4 全量装配发布通道

> 2026-10-12 新增需求：试验放宽几何标准以提高通过率，标准仍在验证。旧冻结任务的严格结果继续保留，其自动发布会因本文件的主动源版本变更而被发布前保护拦截。完成严格计算不表示新标准已经验证或上传；不得绕过版本检查或把旧报告的失败标记直接改为成功。

按当前 Q4 算法处理 A/B 各 40,000 个原模型。新增优先，失败后可删除少量悬空细节，新增＋删除总量≤原体素数2%；原文件字节和保留体素颜色不变。原发布保持不变。

**发布前不把样本通过率当作全量结果。** 只有八万个模型全部处理、八十分包和元数据包全部独立回读后，才生成此目录的 `assembly_summary.json`、`download_manifest.json` 并上传新 Release。是否已实际发布，以 `release_verification.json` 为准；未出现该文件不表示上传已完成。

下载、SHA 校验及可选解压后的逐模型复验：

```text
python tools/download_quality.py --output q4_assembly_80000 --extract
```

每个源 ID 对应一份原模型、原五级提示词、一份明确标识的派生目标，以及实际装配 JSON/TXT/LDR、物理平衡见证、修改记录、仅新增失败证据和报告。失败文件为 `.draft`，不是可用装配。原提示词不自动绑定修改后的目标。

几何成功与假设下自重/完成层静力筛查分别统计；质量、接触面和咬合容量未实物标定，未知咬合力不算物理通过，`staticVerified=null / fullPhysics=false`。派生几何不是语义无损认证。

全量执行使用冻结的代码快照、逐模型可恢复输出与1000模型分包检查点。任何源 SHA、输出校验、预算、Git 工作状态或服务器资源 SHA 不一致都会停止后续发布，不覆盖旧成果。算法见 [Q4说明](../../algorithms/voxel_assembly_q4/README.md)。

## 十二小时平衡调度

`tools/run_quality_balanced.py` 保留旧全量任务已经完成的报告和实际搜索参数，不把它们改标为短预算结果。剩余任务首先调用现有 Q2 全局回溯和局部新增支撑规划器；实际新增方案失败后，再调用现有 Q4 增删 MILP 回退。搜索预算随时间余额缩短，固定2%改动上限、原色、真实stud、接地和全部物理筛查规则。搜索限时不是不可能性证明；短预算可能降低几何成功率。新生成报告额外记录轻量生成器版本和源码SHA，Q4独立几何与物理审核器保持不变。

计算进程按小批次显式退出并重建，控制内存峰值；不依赖可能停滞的 `max_tasks_per_child` 回收。压缩包使用较快的无损压缩，原始字节和完整实际ZIP回读不变，文件写入和实际ZIP回读均以有限队列并行审计。索引逐项记录 `actualSearchOptions` 和 `resultOrigin`，元数据同时保存新旧运行源码证据。

十二小时是尽力达到的总交付目标，包含打包、校验和上传，并非完成保证。预留两小时用于交付与网络上传；超时不会跳过检查、把草稿标成成功，或发布缺少模型的清单。网络、磁盘空间或仓库状态异常会保存成果并停止发布。
