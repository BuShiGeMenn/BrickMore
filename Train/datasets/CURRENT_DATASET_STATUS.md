# 当前数据集统计口径

当前文档采用 **原全量重铺发布 + 新版 B 批钢琴替换** 的整合口径。该统计根据下列两份发布报告计算，并非重新运行全量验证产生的新汇总文件。

| 项目 | 数量或说明 |
| --- | --- |
| 模型 | 80,000，21 类，48³ 网格 |
| 描述 | 每个模型 L1–L5 共五条；约 400,000 条中英双语记录（每条含英文描述） |
| 几何通过 | 79,301 / 80,000（99.13%，四舍五入） |
| 几何未通过 | 699 |
| 物理稳定性 | 未完成全面验证；几何通过不等于物理稳定或可实际组装 |

## 版本与计算

[2026-10-13 全量重铺报告](retile_assembly_80000/summary.json)记载 79,298 个几何通过，其中 B 批钢琴 1,902 / 1,905 通过。[2026-10-14 新版 B 钢琴报告](piano_b_supported_1905/summary.json)记载 1,905 / 1,905 通过。以新版替换同一批次的全部 1,905 个钢琴槽位，其他 78,095 个模型沿用旧全量发布，因此 **79,298 − 1,902 + 1,905 = 79,301**。新版钢琴为重新生成的源模型，模型 ID 沿用原槽位；其几何与提示词以新版为准。

79,298 / 80,000 是旧全量发布的历史统计；更早的 7,902 也是不同处理版本的历史结果。各历史报告按其原有范围保留，不应混作当前整合统计。此几何通过口径采用相应发布的砖库、接地与连接规则，允许多个分别接地的组件；不能据此声称所有模型均为单一凸点连通组件。

## 下载和使用边界

[原始 A/B 分片下载](README.md)提供旧原始版本，不会自动替换 B 批钢琴，也不等同于经过整合后的训练数据。要查看整合版本，可使用[新版钢琴说明](piano_b_supported_1905/README.md)中的替换预览，或下载其链接的完整预览包。若用于训练，应确保模型、五级描述、索引和几何通过标签均取自同一版本，并根据实际使用的训练清单报告数量；当前统计本身不证明某次训练已经使用替换数据。原始分片的索引、哈希及去重报告只证明其对应版本，不自动适用于新版钢琴。

数据通过程序化几何生成；派生砖块目标可能按各版本规则对源占用作有限修改。报告的通过结果仅表示相应几何检查，不代表文本语义质量或完整物理认证。
