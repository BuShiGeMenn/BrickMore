# 放宽几何档：多接地组件的真实 stud 装配

独立发布通道，不覆盖原模型、Q4严格结果或旧Release。通过率以八万模型全量实测为准；60%是目标，不是预先写入的通过数。未出现 `release_verification.json` 表示尚未确认发布。

## 明确降低的几何标准

允许多个独立组件；每个组件必须存在通过真实上下stud接触到实际地面的路径。允许从上方积木连接的悬挂细节，但没有接地路径的独立悬空组件仍失败。不要求单一整体、不设人为的支撑比例/悬挑距离/前缀组件数量阈值；不认证逐砖安装顺序。

保留完整、同色标准砖覆盖、无碰撞、48格边界、原色、局部新增及新增＋删除≤原体素数2%的硬检查。新增连接件是实际导出的标准砖，占用真实体素和预算；不是在图中把地面或侧面虚拟连接。删除仍须先有真实的仅新增失败证据，且只能删除原几何中符合旧保护规则的少量细节。

所有严格成功结果先做独立验证再保留。新生成结果采用完整原色分块、局部真实连接砖和真实stud接地流联合求解。流变量只证明可达性，不是承力；两个几何检查器独立从实际砖和上下接触重建组件，不通过同处地面把组件并为一体。

## 物理筛查不降低

沿用旧Q3质量假设、实际接触几何、无锚定地面、自重力与力矩方程及见证残差检查，仅明确替换几何准入为本档。最终状态与全部完成层逐项筛查。上方悬挂、咬合拉力不足、未标定咬合容量和超时会如实区分；几何通过不等于物理通过。始终 `staticVerified=null / fullPhysics=false`，质量/接触参数未经实物标定。仍没有实物参数时，未知咬合力不能判为物理通过。

每源ID的原模型和五级提示词字节保留；修改后的目标另存为 `_q5_` 派生ID，不自动重绑原训练提示词。成功档和 `.draft` 文件、原/派生hash、逐点修改RGB与比例、旧成功保留证据、实际JSON/TXT/LDR、力平衡见证与源码均保留。

全量完成并从实际80个ZIP独立回读CRC/SHA、双几何检查、修复门槛和物理见证之后才发布81个资源。旧冻结Q4的自动发布因明确的源版本保护暂停，新通道采用新的完整冻结计划。中断时保留检查点，不跳过校验。
