## 一、背景(30 秒版)

这个项目是 **BrickGPT-Qwen3-1.7B-BrickMore-48** 模型(输入一句话,输出 48³ 网格/20 砖型的乐高砖块布局)的**评测与筛选**工作。

- 21 个类别 × 5 个等级 = **105 组**,每组原本有 6 个"同提示词不同生成"的候选,由 5 位同事人工选出最佳(机器判定后)。
- 其中 **26 组全军覆没**(人工判定"全部不合格"),后来:
  - 用**训练集模板**重新写提示词、重生成了一批(第二轮 60 个 → 保留 12 个;第三轮补缺 35 个);
  - 另一位同事也做了新尝试(91 个,机器验证后 72 个可用)。
- 目前合并成 **112 个合格模型**(原人工判决 50 + 第二轮 12 + 同事验证通过 50),**还差 7 组**没有可用模型——这 7 组就是第三轮的 35 个候选(7 组 × 5 个),等你看图挑出每组的最佳。

**关键概念(看图时用得上)**:
- "原版(raw)" = 模型直接生成的结构;"重铺版(stitched)" = 数学兜底求解器在**保持形状、体素零增删**的前提下重排砖块,使其成为**单一 stud 连通整体**(能真实拼起来)。
- 每个候选页都有【看重铺版】按钮;能拼性是机器已验证的(35/35 通过),**你只需要判断形状像不像这个物体、质量好不好**。
- 判断"不合格"也完全可以——原人工判决就淘汰了 26 组,标准是"作为该物体的乐高模型不可接受"。

## 三、你的任务(共 3 步,约 1-2 小时)

### 第 1 步:审查第三轮候选

```bash
cd 候选审查_第三轮
python server.py          # 默认端口 8126;如被占用: python server.py 8127
```

浏览器打开 **http://127.0.0.1:8126/**

页面上 7 段,每段 5 个候选:
`basket · L2` / `bench · L4` / `bench · L5` / `mug · L3` / `mug · L4` / `mug · L5` / `table · L5`

操作:左键拖动旋转、滚轮缩放、右键平移;每张卡可【看重铺版/看原版】和【放大查看】。
**为每组选 1 个最好的**(或判该组全部不合格)。

### 第 2 步:填写 picks_round3.json

用记事本打开包根目录的 `picks_round3.json`,为每组填**候选 ID**(页面卡片标题上的 ID),全不合格填 `null`:

```json
{
  "basket_L2": "basket-L2-Q03",
  "bench_L4": "bench-L4-Q01",
  "bench_L5": null,
  "mug_L3": "mug-L3-Q05",
  "mug_L4": "mug-L4-Q01",
  "mug_L5": "mug-L5-Q03",
  "table_L5": "table-L5-Q01"
}
```

> ID 里的 Q01/Q03/Q05/Q07/Q09 就是候选序号;可参考各卡片下方的提示词(英文+中文)对照选择。


脚本会输出:`最终展示_完成/`(105 组完整页面 + 模型)和 `最终清单.csv`。

**回传**:把 `最终展示_完成.zip`(整目录压缩)+ `最终清单.csv` + 你填的 `picks_round3.json` 发回即可。

## 四、页面说明

- 每个卡片标题带**来源徽章**:
  - 蓝「人工判决最佳」= 原五人评审选出的最佳;
  - 绿「第二轮重做」= 用训练集模板重生成后保留的;

- 「看重铺版/看原版」切换:重铺版=可拼版(形状不变、砖块重排);原版=模型直出。
- 缩放/拖拽在各卡片内独立;大图模式点【放大查看】,Esc 关闭。
- 页面首屏加载全部模型需要 5-10 秒(本地文件,无需联网)。

## 五、注意事项 / FAQ

1. **不需要 GPU、不需要模型权重、不需要 Blender**——剩余工作只是看图 + 跑一个纯 Python 脚本(标准库,Python 3.8+ 均可)。
2. 端口被占用:给 `server.py` 传一个数字参数即可(如 `python server.py 8131`)。
3. 页面空白/模型不显示:先确认地址栏端口对;再 Ctrl+F5 强刷。若仍 404,检查 `models/` 目录是否完整(应当是 `候选审查_第三轮/models/` 70 个 .glb,`最终展示/models/` 300+ 个 .glb)。
4. **不要移动/删除 `models/`、`static/js/`、`static/utils/`**——页面依赖这些相对路径。
5. 判断有分歧时:优先保留"看起来像物体、细节可辨"的;原人工判决的 26 组全灭说明"能拼 ≠ 像物体"。
6. 时间紧可只做第 1、2 步(填完 picks 发回),最后一步可以在主工作区跑。
