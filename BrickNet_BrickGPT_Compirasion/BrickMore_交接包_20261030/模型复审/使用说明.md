# BrickMore 模型复审

在交接包根目录运行：

```powershell
python .\模型复审\server.py
```

浏览器打开 http://127.0.0.1:8130/ 。端口占用时可运行 `python .\模型复审\server.py 8131`。

复审范围：camera L2、car L3/L4/L5、guitar L1、piano L5、vessel L1。

- 逐组选用一个模型，或选择“全部不合格，需重生成”。当前采用的模型只作对照，不会自动算作已确认。
- 支持旋转、缩放、平移、同步视角、原版/重铺版切换和放大查看。重铺保持造型不变。
- 汽车组共享五个已有试作；其中部分文件带其他等级的提示词，请结合本组目标判断。吉他 L1 和船 L1 暂无其他现成候选。
- 结果自动写入交接包根目录 `picks_review.json`；刷新或重启服务可继续选择。文件写入失败时仍可导出 JSON 备份。
- 页面右上角可导出 JSON 和 CSV，包含所选候选、原版/重铺版路径、复审备注和待重生成组。尚未选择的组会明确标为待复审。
- 这次复审不改 `picks_round3.json`、最终展示目录、清单或已生成 ZIP。完成复审后，再根据新的选择合并交付。

站点直接复用相邻 `最终展示/static` 的 three.js 和 `最终展示/models` 的 GLB 文件，请保留交接包目录结构。仅使用 Python 标准库和包内静态资源，无需联网或安装依赖。
