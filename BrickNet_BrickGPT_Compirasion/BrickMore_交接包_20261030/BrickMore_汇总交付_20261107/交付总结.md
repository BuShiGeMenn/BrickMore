## 文件与打开方法

- `展示/`：独立的离线展示站与页面实际引用的模型。
- `模型总清单.csv`：全部展示条目，包含英文及中文提示词、模型路径、来源与复审状态。
- `本轮新增与替换清单.csv`、`选择与替换记录.json`：本轮七组的更新记录。
- `资料与记录/`：原选择文件、生成清单、提示词、模型版本及完整原始生成 ZIP。
- 新候选的 GLB、LDR、TXT、原始输出、几何 JSON、报告和图片位于 `展示/models/regen/<模型 ID>/`。
- 原包中已淘汰的 2 次尝试保存在原始生成 ZIP 中，不列入主展示。

在本目录运行：

```powershell
python .\展示\server.py 8140
```

浏览器打开 http://127.0.0.1:8140/ 。服务和页面仅使用 Python 标准库与包内静态资源。
